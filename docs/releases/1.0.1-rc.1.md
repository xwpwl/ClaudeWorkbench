# Claude Workbench 1.0.1-rc.1

- Version: `1.0.1-rc.1`
- Channel: `rc`
- Scope: controlled closed Beta only

Claude Workbench 是独立第三方软件，与 Anthropic、OpenAI 及其关联公司不存在官方隶属、授权或背书关系。

## Beta scope and signing

This candidate is intended only for a small, controlled Beta cohort. It is not approved for public general availability and has not been distributed by the release pipeline. This test build is unsigned, so Windows may display SmartScreen or unknown-publisher warnings.

## Updates and database safety

No production update feed is configured. The loopback feed used by release acceptance is a local test fixture only and must not be described or used as a production feed. Before a controlled update can be installed, Claude Workbench will create and verify an application-owned database backup; a failed backup blocks installation rather than risking the existing database.

## Known limitations

- The software license decision and privacy terms are not final.
- Code signing, a production update feed, publishing identity/contact details, product-name review, and external Windows acceptance evidence remain unresolved.
- Historical `1.0.0` update provenance is not trusted; no production upgrade-chain success is claimed.
- Update acceptance is limited to an isolated, non-releasable `1.0.1-rc.0` fixture and separate installer-over-install checks.
- This release must not be described as public-GA ready.
